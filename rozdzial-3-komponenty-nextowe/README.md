# Rozdział 3 - Komponenty nextowe

Poznajemy wbudowane komponenty Next.js, które ułatwiają i optymalizują pracę z obrazami, linkami, fontami i skryptami.

## Zakres

- `next/image` - wbudowana optymalizacja obrazów
- `next/link` - nawigacja po aplikacji
- `next/font` - optymalizacja fontów
- `next/script` - kontrola ładowania skryptów zewnętrznych

## Materiały

Materiały (prezentacja, nagranie, zadanie) do tego rozdziału umieszczamy w tym folderze.
